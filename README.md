# Reis Barbearia — Landing Page

Static landing page built with **Tailwind CSS 4** + **daisyUI 5** (loaded via CDN — no build step).

## Publish on GitHub Pages
1. Create a new repository and upload `index.html` and the `assets/` folder to the root.
2. Go to **Settings → Pages** → Source: *Deploy from a branch* → `main` / `root` → Save.
3. The site will be live at `https://<your-user>.github.io/<repo>/`.

## Edit
- **Photos:** replace files in `assets/` (keep the same names) or change the `src` / `background-image` in `index.html`.
- **Colors / fonts:** edit the `@theme` block at the top of `index.html`.
- **Reviews:** replace `[INSERIR AVALIAÇÃO REAL DO GOOGLE]` with real Google review text.
- **Booking link:** all "Marcar agora" buttons point to Fresha.
